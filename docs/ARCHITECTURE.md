# 架构说明

## 桌面端

桌面端入口是 `main.py`，使用 PySide6 构建原生 Windows 软件。

核心结构：

- `QMainWindow`：主窗口、菜单栏、状态栏。
- 左侧导航：切换硬件监控、图片工作站、视频工作站、模型部署等页面。
- `QStackedWidget`：承载不同功能页面。
- `QThread`：用于模型部署和耗时任务，避免界面卡顿。
- `QTimer`：用于硬件状态定时刷新。

图片处理链路：

1. 读取原图和可选参考图。
2. 根据预设和用户参数进行色彩、光影、清晰度、质感调整。
3. 根据输出策略计算目标分辨率。
4. 使用分阶段放大 + 原图亮度边缘引导进行超清输出。
5. 保存 PNG。

视频处理链路：

1. 导入原视频。
2. 检测本机 GPU、显存、FFmpeg 和硬件编码器。
3. 根据用户选择的专业模式生成编码参数。
4. 通过异步任务执行转码、锐化、降噪、补帧等步骤。

模型部署链路：

1. 选择模型或用户自定义模型。
2. 检查本地目录、服务端口和依赖。
3. 异步执行部署步骤并实时写入日志。
4. 状态页检测 ComfyUI/FLUX 服务是否可用。

## 移动端

移动端位于 `mobile_app/`，使用 Flutter 实现。

核心结构：

- `lib/main.dart`：应用入口、主题、页面导航。
- 模型库页面：下载、导入、启用和切换本地模型。
- 任务队列：保存用户在手机端发起的本地 AI 任务。
- 动画系统：页面进入、模型卡片状态切换和操作反馈。

## 发布策略

源码仓库只保存：

- 源码。
- 脚本。
- 文档。
- Release manifest 和校验文本。

不保存：

- `build/`、`dist/`。
- APK、ZIP、EXE 等二进制发布包。
- 模型权重和用户输出文件。
